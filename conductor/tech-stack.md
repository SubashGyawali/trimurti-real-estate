# Tech Stack: Trimurti Real Estate

## 1. Core Frameworks
*   **Frontend:** Next.js 16 (React 19, App Router) - Provides high-performance, SEO-friendly rendering and modern routing.
*   **Language:** TypeScript - Ensures strict typing for long-term maintainability and reduced runtime errors.

## 2. UI & Styling
*   **CSS Framework:** Tailwind CSS - Utility-first CSS for rapid, responsive UI development.
*   **Component Library:** shadcn/ui (based on Radix UI) - Accessible, unstyled components for building a custom "Professional/Corporate" UI.
*   **Animations:** Framer Motion - Used for smooth transitions and subtle "Mumbai Warmth" animations.

## 3. Backend & Data
*   **Backend as a Service (BaaS):** Supabase - Handles authentication, PostgreSQL database, and storage (for property images).
*   **Forms & Validation:** React Hook Form + Zod - Ensures robust, type-safe form handling for "Requirement" and "Sell" modules.

## 4. Specialized Integrations
*   **Maps:** Leaflet + OpenStreetMap - Integrated for interactive "Hyper-Local" property mapping without the high cost of Google Maps.
*   **Email Service:** Resend - Reliable delivery for inquiry notifications and user communications.

## 5. Development Tools
*   **Package Manager:** pnpm - Efficient, fast package management.
*   **State Management:** React Hooks (native) - Primarily using local state and Supabase client for data fetching.
